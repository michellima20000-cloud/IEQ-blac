# IEQ-black (Backend)

API Backend desenvolvida em Node.js com Express e TypeScript.

## 🚀 Como executar

### 1. Instalar dependências:
```bash
npm install
```

### 2. Modo Desenvolvimento:
```bash
npm run dev
```

### 3. Build e Produção:
```bash
npm run build
npm start
```

## 🔌 Endpoints

- `GET /api/health` - Checagem de integridade da API
- `GET /api/info` - Informações da versão e serviço
